# 💧 Water Potability Prediction Using Machine Learning

A Streamlit-based machine learning web application that predicts
whether water is potable based on water-quality parameters.

## Features

- Dataset analysis
- Missing-value analysis
- Interactive data visualization
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors
- Model comparison
- User-input water prediction
- Upload custom compatible datasets

## Dataset Features

- pH
- Hardness
- Solids
- Chloramines
- Sulfate
- Conductivity
- Organic Carbon
- Trihalomethanes
- Turbidity

## Target

- 0 = Not Potable
- 1 = Potable

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
